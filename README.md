# Next.js + Tailwind Portfolio Template

A clean, customizable developer portfolio built with **Next.js App Router**, **Tailwind CSS**, and **Framer Motion**.  
Perfect for frontend devs looking to showcase their work.

## 🚀 Features

- Next.js 15+ App Router
- Tailwind CSS 4
- Framer Motion page transitions
- Responsive and accessible design
- Modal project cards
- Contact form with API endpoint

## 🛠️ Setup

```bash
git clone https://github.com/yourusername/portfolio-template.git
cd portfolio-template
npm install
npm run dev


## ✉️ Contact Form Setup

This project includes a basic contact form handler using `nodemailer` and Gmail. To enable form submissions, create a `.env.local` file in the project root and add the following:

```env
EMAIL=your.email@gmail.com
EMAIL_PASS=your-gmail-app-password
RECEIVER_EMAIL=your.destination@example.com
